The ``print_square`` function prints a square of '#'.

>>> print_square = __import__('4-print_square').print_square

Basic usage
>>> print_square(2)
##
##

Zero size prints nothing
>>> print_square(0)

Single cell
>>> print_square(1)
#

>>> print_square(-1)
